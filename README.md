## 💻 Run Locally

Follow these steps to run the portfolio on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/kamrul2211/Professional-portfolio0002.git
```

### 2. Open the project folder

```bash
cd Professional-portfolio0002
```

### 3. Run the website

Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.

> Replace the repository URL and folder name above if your actual GitHub repository uses a different name.
